### New Features Planned
- **Updating File Structure**: The current File structure uses too much tokens for the Ai generation and its pretty hard to manage. So I'm gonna use a simple structure. 'File Path': 'File Content'. This will make it easier to manage and also reduce the tokens used for Ai generation.

- **Using the new Tanstack Start**: Currently I'm using only React. Which has a lot of limitations for navigating between pages and fetching data. So I'm gonna use the new Tanstack Start which is a framework for building web applications. It has a lot of features like routing, data fetching, and more. This will make it easier to build the application and also improve the performance.

- **Adding a new feature for generating code snippets**: Currently the application only generates code for the entire file. But I'm planning to add a new feature where the user can select a piece of code and generate code snippets for that. This will make it easier for the user to generate code for specific parts of the file.
